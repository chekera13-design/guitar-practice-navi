# EX5の横スクロール：実機用の軽量観測ページ

本番ファイルを置換する修正ではありません。`diagnostics`内のHTML/JSを公開サイトの同じ`diagnostics`ディレクトリへ追加した場合だけ利用できます。現在こちらから公開先へのアップロードは行っていません。

1. `https://guitar-practice-navi.pages.dev/diagnostics/scroll-performance.html`を開く。
2. いつも横スクロールが気になる向きで基礎編EX5を開く。スマホは横向き。BPMは60のまま。
3. 下部の「自動スクロール」「計測を準備」を選び、アプリの「練習」を押す。
4. 自動的に移動し始めてから30秒間観測する。その間、指で譜面を動かさず、画面の向き・倍率を変えず、他のアプリへ切り替えない。
5. 「ログ保存」でJSONを保存する。まずFire HD 10、可能ならAQUOSでも同じEX5・60 BPM・横型TABで1回ずつ行う。

指との比較も必要な場合は練習を停止し、「指でスクロール」を選んで再び計測を準備する。譜面の途中の位置から左・右へ適宜動かす。指を止めた時間もログに入るため、自動スクロールと停止フレーム比率を直接比較しないこと。

観測対象は画面更新の呼び出し間隔、音声時計の進み幅、実際のscrollLeft、50ms以上の長い処理、画面状態。曲線、数字、描画設定、CSS、音声、練習時計、スクロール設定は変更しない。SVGのgetBBoxやフォント計測を毎フレーム呼ばない。

注意：RAFの呼び出し頻度はGPUが実際に表示できたFPSとは別。画面更新が安定しているのに体感が悪い場合は、描画・合成負荷の追加調査が必要。iframe経由の観測と少量の計測負荷があり、通常ページと完全に同条件ではない。
